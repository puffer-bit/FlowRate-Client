# FlowRate identity assets

The selected FR headphones design, using the application accent color `#6C63FF`.

## Files and uses

| Asset | Use |
| --- | --- |
| `svg/app-icon.svg` | App icon with rounded purple background |
| `svg/app-icon-square.svg` | Full square background for consumers that apply their own mask; this is not an Android adaptive icon resource |
| `svg/mark-purple.svg` | Transparent purple mark for light backgrounds |
| `svg/mark-white.svg` | Transparent white mark for dark backgrounds |
| `svg/mark-dark.svg` | Transparent dark mark for monochrome printing and light backgrounds |
| `svg/tray-*.svg` | Dedicated compact geometry with heavier lettering for small sizes |
| `svg/favicon.svg` | Compact white mark on a purple tile for browser tabs |
| `svg/wordmark-on-light.svg` | Horizontal logo with dark lettering for light backgrounds |
| `svg/wordmark-on-dark.svg` | Horizontal logo with white lettering for dark backgrounds |
| `flowrate.ico` | Windows icon with 16, 24, 32, 48, 64, 128 and 256 px frames |
| `favicon.ico` | Browser favicon with 16, 32 and 48 px frames |
| `png/` | Transparent or background-filled PNG exports, matching their SVG source |
| `preview.svg`, `preview.png` | Comparison sheet; backgrounds belong to the preview only |

App PNG sizes: 16, 24, 32, 48, 64, 128, 256, 512 and 1024 px. For a small tray icon, use the dedicated tray assets rather than the app icon. Tray PNG sizes: 16, 20, 24, 32 and 48 px. Transparent marks: 64, 128, 256 and 512 px. Horizontal logo exports: 1700 × 512 px.

All individual SVG artwork uses paths and shapes. Wordmark lettering is outlined and does not require a font. SVG files are self-contained with no external images, scripts or linked fonts.

This is the active application icon set. The desktop uses it for window icons, the Windows executable, the tray outside voice sessions and Windows/Linux release packaging. Voice status glyphs remain in use during sessions.

`Android/` contains native resources linked by the Android project: legacy launcher PNGs for five densities, an adaptive foreground and background, and a monochrome layer for themed icons. These resources are regenerated by `build.py` alongside the SVG, PNG and ICO exports.

## Rebuild

Run `python3 src/Client/Client.Avalonia.Assets/AppIcons/Headphones/build.py` from the client repository root. Requires PyGObject with Rsvg 2.0, Pycairo and Pillow. The builder includes the selected mark geometry and uses Noto Sans Bold for outlining the wordmark.

Validation: SVG XML parsing, successful rendering with librsvg, PNG decoding and ICO frame counts. The preview was visually reviewed; appearance in a running operating-system tray has not been checked.
